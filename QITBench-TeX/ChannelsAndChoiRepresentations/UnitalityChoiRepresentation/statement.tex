Let $\cE:\cL(\cH)\to\cL(\cH)$ be a completely positive map on a
$d$-dimensional Hilbert space. Fix an orthonormal computational basis
$\{\ket{i}\}_{i=1}^d$ for $\cH$, use it on two copies $\cH_A$ and $\cH_B$, write $\cE_B$ for its action on the second copy, and set $\ket{\Gamma}_{AB}=\sum_{i=1}^{d}\ket{i}_A\ket{i}_B.$ Define the unnormalized Choi matrix by $J_{\cE}=(\id_A\otimes\cE_B)(\ket{\Gamma}\bra{\Gamma}_{AB}).$ Prove that $\cE$ is unital, meaning that $\cE(\Id)=\Id,$ if and only if
$$
\Tr_A(J_{\cE})=\Id_B.
$$
