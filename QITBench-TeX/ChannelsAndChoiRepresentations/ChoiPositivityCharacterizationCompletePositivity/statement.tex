Consider the linear map $\Phi:\cL(\cH_A)\to\cL(\cH_B)$ where $d_A=\dim\cH_A$. Fix an orthonormal computational basis
$\{\ket{i}\}_{i=1}^{d_A}$ for $\cH_A$, let $A'\cong A$, write $\Phi_{A'\to B}$ for the same map acting on the input copy $A'$, and set $\ket{\Gamma}_{AA'}=\sum_{i=1}^{d_A}\ket{i}_A\ket{i}_{A'}.$
Define the unnormalized Choi matrix of $\Phi$ by
$$
J_{\Phi}
=
(\id_A\otimes\Phi_{A'\to B})
(\ket{\Gamma}\bra{\Gamma}_{AA'}).
$$
Recall that $\Phi$ is completely positive when $\id_R\otimes\Phi$ is positive on $\cL(\cH_R\otimes\cH_A)$ for every finite-dimensional reference Hilbert space $\cH_R$. Let $\Pos(\cH_A\otimes\cH_B)$ denote the cone of positive-semidefinite operators on $\cH_A\otimes\cH_B$.

Prove that $\Phi$ is completely positive if and only if
$$
J_{\Phi}\in\Pos(\cH_A\otimes\cH_B).
$$
