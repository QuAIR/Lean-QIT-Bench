Let $A$ and $B$ be qubit systems with fixed computational bases. Determine whether there exists a global unitary $V_{AB}$ on $\cH_A\otimes\cH_B$ with the following property: for every qubit density operator $\rho_B$ on $B$, write $\rho_A$ for the operator on $A$ with the same matrix representation in the chosen computational bases; the unitary maps the input state $\omega_{AB}=(\Id_A/2)\otimes\rho_B$ to a state whose two marginals satisfy
$$
\Tr_A\!\left[V_{AB}\omega_{AB}V_{AB}^\dagger\right]
=
\frac{\rho_B}{2}+\frac{\Id_B}{4}
$$
and
$$
\Tr_B\!\left[V_{AB}\omega_{AB}V_{AB}^\dagger\right]
=
\frac{\rho_A}{2}+\frac{\Id_A}{4}.
$$
